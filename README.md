# Thabang Portfolio (alt)

Alternate build of Thabang's personal portfolio. Static HTML/CSS/JS + a `scripts/verify.js` validation step (`npm test`).

This repo mirrors the live portfolio at https://thabs1234.github.io/portfolio/. The canonical, actively-deployed copy lives in the `portfolio` repo; this one is kept for the `npm`-based verification workflow.

## Commands
- `npm test` / `npm run verify` — runs `node scripts/verify.js`.
