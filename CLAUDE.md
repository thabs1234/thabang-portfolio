# CLAUDE.md — thabang-portfolio

## What this is
Thabang's personal portfolio site. Static: `index.html` + `script.js` + `styles.css`, plus a `scripts/verify.js` (run with `npm test` / `npm run verify`). No framework deps.

## Commands
- `npm test` / `npm run verify` — runs `node scripts/verify.js` (validation/lint of the site).

## Notes
- Keep it dependency-free. Edit HTML/CSS/JS directly; run verify before committing.
